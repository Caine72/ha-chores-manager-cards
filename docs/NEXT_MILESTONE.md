# Current milestone: 0.6.0 Quick Chore card

This release adds a reusable household interface for shared chores that need
fast status, child claim, manual completion, and reset controls.

## Scope

- select multiple shared chores and children through the visual editor;
- show claimant portraits, localized completion text, and profile-formatted time;
- claim by portrait using first-unfinished or configurable time windows;
- complete manually without points through Chores Manager `0.9.0`;
- optionally reset manual or child-claimed occurrences;
- customize layout density, status arrangement, portraits, and manual icons.

See [the release notes](RELEASE_0.6.0.md).
