# Documentation images

The card screenshots use the fictional **Acceptance Avery** test child and synthetic Chores Manager state. They were rendered from the repository's production card bundle; they are not screenshots of a real household profile.

`acceptance-avery-avatar.png` is an AI-generated generic illustration created for these public documentation examples. It contains no real person's likeness, text, branding, or household data. The same image can be assigned to a Home Assistant Person used for local acceptance testing.

The four card images correspond to:

- `overview-card.png`
- `daily-card.png`
- `history-card.png`
