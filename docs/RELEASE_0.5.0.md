# Chores Manager Cards 0.5.0

- Shows a shared chore as claimed by the child who completed it.
- Disables a shared chore on another child's Daily card, preventing that child
  from undoing the claimant's completion through the card.
- Keeps the claimant's own Daily-card row available for undo.

Requires Chores Manager `0.8.0` or newer.
